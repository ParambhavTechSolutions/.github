## 🚀 About Parambhaav

**Parambhaav** is a builder-first studio that makes products across **IoT devices, mobile apps, backend APIs and the cloud**. Quality engineering is part of every build, not an afterthought.

- 👤 **Founded by:** [Prashanth Galagali](https://github.com/galagaliprashant), a Senior SDET with 9+ years across IoT, mobile, API and cloud (Samsung R&D, Grab).
- 🔭 **Current focus:** End-to-end connected products where data flows device → mobile app → AWS → APIs → web dashboard.
- 🛠️ **Building in public:** Every product follows *Build → Demo → Sell*, and we share progress as we go.
- 🌱 **Exploring next:** Quality tooling, test automation and AI-assisted products.
